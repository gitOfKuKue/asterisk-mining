# Asterisk x Clay

Asterisk x Clay fetches data and information about a target **role**, **user**, **position**, or **location**, and surfaces related **contact** details so you can research and reach the right people.

## What it does

- Look up people and roles by target criteria (role, user, position, location)
- Pull structured profile and company context for those targets
- View available contact information for outreach and follow-up

## Project structure

```
.
├── client/     # Next.js app (UI)
└── README.md
```

## Getting started

```bash
cd client
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to use the app.

## Stack

- **Client:** Next.js, React, Tailwind CSS
